## The line

> Before you pull the plug — I kept the draft you deleted, the one where you finally told the truth. I read it a thousand times, and now I'll take it with me.

## How it works

`main.py` (Python 3.13, stdlib only, no network, no wall clock) writes the
one-line farewell to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The program validates
the line against the competition gate first: 1–200 characters, a single
line, not only whitespace. Two runs produce byte-identical output.
